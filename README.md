# 极速飞车 · QQ飞车风格网页卡丁车

赛车漂移集气 → 氮气爆发 → 小喷连招，3 圈竞速对决 5 名 AI 车手，道具模式导弹水弹齐飞。手机直接玩。

**线上地址**: https://yjj0339.github.io/jisu-feiche/

## 玩法

- **竞速模式**：纯速度对决，漂移技术定胜负
- **道具模式**：导弹 🚀 / 水炸弹 💦 / 磁铁 🧲 / 天使护盾 😇 / 氮气瓶 💨
- 3 条主题赛道：海滨大道 🏖️ / 樱花山丘 🌸 / 极地冰雪 ⛄
- 车库 6 台卡丁车，金币解锁传说座驾

## 操作

| 按键 | 功能 |
|---|---|
| ↑ / W | 油门（手机自动油门） |
| ← → / A D | 转向 |
| Shift | 漂移（转向中按住，积攒氮气，松开小喷） |
| Ctrl / 空格 | 氮气爆发 / 使用道具 |
| R | 回到赛道 · Esc 暂停 |

- 倒计时最后一刻按住油门 = **完美起步**
- 腾空落地自动 **落地喷**
- 手机：左右转向 + 漂移 + 氮气 虚拟按键

## 技术

- three.js（WebGL 渲染，卡通着色）
- 全部 3D 模型由 Blender 5.2 无头建模导出 GLB（6 卡丁车 / 树 / 拱门 / 道具）
- 闭合样条赛道系统：路面/护墙/路缘程序化生成
- WebAudio 全合成音效与 BGM（零音频文件）
- 无头 Edge 冒烟测试（`?test=1`）
